# Pastel Blue Birthday Game 🩵

A mobile-friendly birthday mini-game website inspired by the reference screenshots.

## Features
- Pastel blue welcome page
- Tap-to-catch hearts game
- Word puzzle
- PIN screen for memories
- Personal birthday letter and final surprise

## Personalize
Edit the `CONFIG` object at the top of `script.js`:
- `name`
- `pin` (4 digits)
- `pinClue`
- `loveLetter`

## Publish on GitHub Pages
1. Create a public repository at https://github.com/new
2. Upload `index.html`, `style.css`, `script.js` (and any photos/audio you add) to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch, branch `main`, folder `/(root)`, then Save.
5. Your site will be published at `https://USERNAME.github.io/REPOSITORY/`.

This is a static website; no backend is required. The PIN is a playful interaction, not real security.
